# Ceramics portfolio

A letter-size PDF of Mennatallah Rihan’s recent pottery, assembled from the original photographs.

- **PDF:** [Mennatallah_Rihan_Ceramics_Portfolio.pdf](./Mennatallah_Rihan_Ceramics_Portfolio.pdf)
- Objects are unaltered (no filters, retouching, or background removal).
- Duplicate frames of the same piece were reduced to the clearest detail views.
- Complementary angles of one piece (interior/exterior) share a page.

Rebuild:

```bash
python3 ceramics-portfolio/build_portfolio.py
```
